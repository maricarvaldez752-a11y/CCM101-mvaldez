# Laboratory 3 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity focuses on exploring and comparing major cloud computing platforms, including Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Objectives

- Explore AWS, Microsoft Azure, and Google Cloud.
- Research their global infrastructure and core services.
- Compare the three major cloud platforms.
- Recommend cloud platforms based on different business requirements.
- Practice Linux system investigation.
- Document the activities using Markdown and GitHub.

## Activities

- AWS Research
- Microsoft Azure Research
- Google Cloud Research
- Cloud Platform Comparison
- Client Recommendations
- Linux Server Investigation
- Multi-Cloud Reflection
