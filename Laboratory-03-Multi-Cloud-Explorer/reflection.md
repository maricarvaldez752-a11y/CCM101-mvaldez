
# Reflection

This laboratory activity helped me understand the differences between AWS, Microsoft Azure, and Google Cloud. Before doing this activity, I only had a basic idea of what cloud computing was. After researching the three platforms, I learned that cloud providers offer many services for computing, storage, databases, networking, security, artificial intelligence, and other business needs.

The cloud platform that impressed me the most was Google Cloud because of its services for artificial intelligence, machine learning, data analytics, and Kubernetes. However, I also learned that each cloud provider has its own strengths, so there is no single platform that is always the best for every organization.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, databases, networking, identity management, and Kubernetes services. They also have global infrastructure that allows organizations to run their applications in different locations.

Business requirements are important when choosing a cloud platform. A company should consider its budget, existing technologies, workload, security needs, performance requirements, and expected growth. For example, Azure can be a good option for an organization that already uses Microsoft technologies, while Google Cloud can be useful for AI and data-related workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider requires more than just looking at the available services. I need to understand the actual needs of the client before making a recommendation. I also learned how to compare services from different cloud providers and explain why a particular platform may be suitable for a specific business.

Overall, this activity improved my understanding of multi-cloud computing. I also became more comfortable using Markdown and organizing my work in GitHub. The activity helped me see how cloud computing concepts can be applied to real business situations.
