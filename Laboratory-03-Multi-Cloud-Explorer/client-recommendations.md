# Client Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: Google Cloud

I recommend Google Cloud for the startup because the company has a limited budget but expects to grow quickly. Google Cloud provides services that can support application development and scaling as the business grows. The company can start with the resources it needs and increase them as demand increases.

### Recommended Services

- Cloud Run
- Cloud Storage
- Cloud SQL

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

I recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with Microsoft technologies, which can make it easier for the university to manage its existing environment. It also provides services for virtual machines, identity management, and databases.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud

I recommend Google Cloud for the AI research company because its work focuses on artificial intelligence and machine learning. Google Cloud provides services that can support AI development, data processing, and large computing workloads. These services can help the company develop and run its AI applications.

### Recommended Services

- Vertex AI
- Compute Engine
- BigQuery

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

I recommend AWS for the global e-commerce company because it needs scalable and reliable infrastructure for customers in different locations. AWS provides many services that can support web applications, storage, and traffic management. These services can help the company handle changing customer demand.

### Recommended Services

- Amazon EC2
- Amazon S3
- Elastic Load Balancing

---
## Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | Google Cloud | Google Cloud provides scalable services that can support a startup as it grows. |
| Enterprise Organization | AWS | AWS provides a wide range of services that can support different enterprise workloads. |
| Microsoft Environment | Azure | Azure works well with Microsoft technologies and services. |
| AI / Machine Learning | Google Cloud | Google Cloud provides services for artificial intelligence and machine learning. |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine (GKE) provides a managed Kubernetes service. |
| Global Web Application | AWS | AWS provides global infrastructure and services that can support scalable web applications. |
