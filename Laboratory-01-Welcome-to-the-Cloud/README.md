# Mission 1: Welcome to the Cloud

## Mission Overview

This mission introduced me to the basic tasks of a cloud infrastructure engineer. I used the KillerCoda Ubuntu environment to practice Linux commands, gather system information, organize files, and document my work using Markdown.

## Objectives

- Learn how to work in a Linux environment.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Practice technical documentation using Markdown.

## Activities Performed

- Created and logged in to the `mvaldez` user account.
- Checked the current username, working directory, and hostname.
- Identified the Linux distribution, kernel version, CPU information, memory, and disk space.
- Created folders for Notes, Reports, and Screenshots.
- Created Markdown files for the activity.
- Prepared the GitHub repository for the Cloud Computing portfolio.
