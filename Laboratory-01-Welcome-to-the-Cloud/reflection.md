# Reflection

This activity helped me understand the basic environment used by a cloud engineer. I learned how to create a user in Linux, check system information, and organize files and folders using different commands. I also learned how Markdown files can be used to document technical information in a simple and organized way.

One of the things I found useful was checking the CPU, memory, disk space, and Linux version of the system. It helped me understand that before working with cloud infrastructure, it is important to know the environment you are working with.

I also learned the importance of keeping my work organized in a GitHub repository. Having my files, screenshots, and documentation in one place makes it easier to track my progress and review what I have learned.

Overall, this activity gave me a better understanding of basic Linux commands, documentation, and GitHub. These skills will be useful as I continue learning more about cloud computing and system administration.
